## Post 2 — miniwyzwanie

Jaki wynik wypisze ten kod?

```java
int lessons = 3;
int xpPerLesson = 20;
System.out.println(lessons * xpPerLesson);
```

Jeśli dopiero zaczynasz: `lessons` to liczba lekcji, `xpPerLesson` to punkty za jedną lekcję, a `*` oznacza mnożenie.

W nauce programowania chodzi o zrozumienie, co robi kod. Od prostych przykładów przechodzisz do własnych rozwiązań.
